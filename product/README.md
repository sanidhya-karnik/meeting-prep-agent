# Kairo - Automated Meeting Preparation

Kairo automatically prepares you for meetings by researching attendees and companies, then creating a prep task on your Google Calendar with everything you need to know.

## What It Does

1. **Monitors your Google Calendar** for upcoming meetings (polls every 5 minutes)
2. **Researches automatically** when a meeting with external attendees is detected:
   - Extracts attendees, companies, and meeting agenda
   - Searches for LinkedIn profiles and professional backgrounds
   - Gathers recent company news and context
   - Checks internal database for past interactions (if configured)
3. **Creates a prep task** 30 minutes before your meeting with:
   - Meeting agenda extracted from the description
   - Company intelligence with recent news links
   - Attendee profiles with LinkedIn links
   - Suggested questions based on meeting context

## Setup

### Prerequisites

- Python 3.11+
- Google account with Calendar access
- Tavily API key (free tier works)

### 1. Clone and Install

```bash
cd meeting-prep-agent/product
pip install -r requirements.txt
```

### 2. Google Calendar API Setup

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create a new project (or use existing)
3. Enable **Google Calendar API**:
   - Go to APIs & Services > Library
   - Search for "Google Calendar API"
   - Click Enable
4. Create OAuth credentials:
   - Go to APIs & Services > Credentials
   - Click "Create Credentials" > "OAuth client ID"
   - Choose "Desktop app"
   - Download the JSON file
5. Save the downloaded file as `credentials.json` in the `product/` directory
6. Add your email as a test user:
   - Go to OAuth consent screen
   - Under "Test users", add your Gmail address

### 3. Get Tavily API Key

1. Go to [tavily.com](https://tavily.com)
2. Sign up for free account
3. Copy your API key

### 4. Configure Environment

```bash
cp .env.example .env
```

Edit `.env`:

```env
# Required
TAVILY_API_KEY=tvly-xxxxxxxxxxxxx

# Optional - leave empty to disable internal search
DATABASE_URL=

# Optional - customize behavior
POLL_INTERVAL_SECONDS=300
CALENDAR_LOOKAHEAD_HOURS=48
PREP_TASK_MINUTES_BEFORE=30
```

### 5. Run

```bash
# First run - will open browser for Google OAuth
python main.py

# Or run once for testing
python main.py --once
```

## Configuration

| Variable | Description | Default |
|----------|-------------|---------|
| `TAVILY_API_KEY` | Tavily API key for web research | Required |
| `DATABASE_URL` | PostgreSQL URL for internal search | None (disabled) |
| `POLL_INTERVAL_SECONDS` | How often to check calendar | 300 (5 min) |
| `CALENDAR_LOOKAHEAD_HOURS` | How far ahead to look for meetings | 48 hours |
| `PREP_TASK_MINUTES_BEFORE` | When to create prep task | 30 min |
| `CALENDAR_ID` | Which calendar to monitor | primary |

## Features

### Agenda Extraction
Kairo extracts agenda items from your meeting description:
- Numbered items (1. 2. 3.)
- Bullet points (-, *, •)
- Items under "Agenda:" header

### Smart LinkedIn Search
Searches for the correct professional by:
- Using quoted search with company name
- Verifying company appears in results
- Falls back gracefully if no match found

### URL Deduplication
Prevents duplicate links like:
- `/newsroom` vs `/newsroom/news`
- Same article from different sources

### Sentence-Boundary Truncation
Text is never cut off mid-word or mid-sentence:
- Truncates at periods, exclamation marks, or question marks
- Falls back to word boundaries with "..."

### Context-Aware Questions
Questions are tailored to meeting type:
- Partnership meetings: "What does success look like?"
- Review meetings: "What areas need attention?"
- Integration meetings: "What's the timeline?"

## Internal Database (Optional)

If you want to include internal context (past interactions, deals, notes):

```bash
# Set DATABASE_URL in .env
DATABASE_URL=postgresql://user:pass@localhost:5432/kairo

# Initialize with sample data
python -m database.init_db --seed
```

The internal search will include:
- Client and contact records
- Deal history
- Past meeting notes
- Activity timeline

## Troubleshooting

### "Access Denied" on first run
- Make sure you added your email as a test user in Google Cloud Console
- Delete `token.json` and try again

### No prep tasks being created
- Check that meetings have external attendees
- Check that prep task doesn't already exist (look for `[PREP:...]` marker)
- Run with `python main.py --once` to see logs

### Wrong LinkedIn profiles
- This can happen with common names
- Kairo now verifies company name appears in results
- Falls back to "Professional at {Company}" if no good match
